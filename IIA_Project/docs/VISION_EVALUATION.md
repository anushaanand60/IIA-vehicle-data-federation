# Photo pipeline: plate, make, model and colour (tuned on 8 cars, tested on 5)

Generated by `python scripts/evaluate_vision.py` on the 39 images of `data/vehicle_photos` (13 freely licensed photos of REG's models, each with a REG plate of exactly that make, model and colour pasted over its own; see `scripts/make_vehicle_photos.py`). Split by source photo: no car is in both halves.

## Thresholds, chosen on the training cars only

CLIP is used zero-shot. The training cars choose how sure it must be before an answer is used, maximising *right - 2 x wrong* (a wrong colour invents a clone signal, so it costs more than silence):

| attribute | threshold | (was) |
|---|---|---|
| make | 0.7 | 0.7 |
| model | 0.7 | 0.7 |
| colour | 0.6 | 0.6 |
