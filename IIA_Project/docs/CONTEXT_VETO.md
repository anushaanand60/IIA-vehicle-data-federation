# Context veto: how many contradictions hold an ACCEPT at REVIEW

Generated by `python scripts/evaluate_context_veto.py` on 405 held-out test reads whose true plate is registered (seed and simulated camera context as in MATCHING_EVALUATION.md: make right 85 %, model 70 %, colour 75 %). A clone is the same read seen with a random other vehicle's make, model and colour.

| policy | honest ACCEPT recall | ACCEPT precision | clones auto-ACCEPTed |
|---|---|---|---|
| no veto | 0.869 | 0.997 | 0.647 |
| any one contradicts | 0.417 | 0.994 | 0.047 |
| two or more contradict (in use) | 0.785 | 0.997 | 0.128 |
| all three contradict | 0.859 | 0.997 | 0.294 |

One contradiction alone must not veto: a camera misjudges colour often enough that recall would halve. Two or more independent contradictions mean a different vehicle, so the plate is identified but the car is not, and a person decides (Data Cleansing's R4 flags the same record as clone evidence).
