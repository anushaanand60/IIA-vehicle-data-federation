## 5. Logistic-regression weights (standardised features)

A positive weight pushes towards "same vehicle"; magnitudes compare because every feature is scaled to unit variance on the training pairs. Regularisation strength C = 0.1 was chosen on validation from [0.01, 0.1, 1.0, 10.0] (ties to the smaller C).

How to read it: the ten string measures are all functions of the same two strings and are strongly correlated, so *within that group* weights trade off (a negative sign on one measure partly cancels a positive sign on a near-copy of it) and only the group as a whole is meaningful. The context weights are independent evidence and read directly. The read-level features (`ocr_confidence`, `read_is_registered`) are the same for every candidate of a read, so their negative weights mean: when the read is confident or is itself a registered plate, every candidate *other* than the exact read is less likely to be the vehicle.

## 7. Decision

**Use `logreg`.** It was the best contender on validation, and on test it ranks the right vehicle first for 90.2% of registered reads (MRR 0.911), ACCEPTs 84.2% of them unattended at 99.7% precision and sends 3.9% of reads to review.

Margin over the runner-up `gbt` (by validation): +0.007 top-1 and +0.014 ACCEPT recall; read by read it is right on 4 test reads `gbt` gets wrong and wrong on 1 it gets right. Over the phase-1 rule resolver: +0.294 top-1 (123 reads won, 0 lost).

Why, in plain sentences (a feature group's worth = logistic regression's test top-1 lost when that group is removed and the model retrained, section 4):

- Blocking finds the plausible plates; every contender then ranks the same candidates, so the differences below are scoring, not retrieval.
- The best single measure is `learned_ocr_similarity` (0.868). Combining all the string measures in one model, with no camera context, gives 0.852 (-0.017): stacking string measures on their own buys nothing -- they all look at the same two strings and fail on the same reads.
- The camera's make, model and colour are worth +0.045: they separate plates one glyph apart, which no string measure can do. This is the main reason a combination beats any single algorithm.
- The learned confusion costs are worth +0.002 inside the combination, because the hand-table distance is still in the vector and carries most of the same signal; on their own they beat the hand table (0.868 vs 0.859).
- OCR confidence is worth -0.002 in top-1: it moves how sure the model is, not which plate comes first.
- Calibration plus validation-chosen thresholds make ACCEPT 98% safe and REJECT reads with no plausible candidate. At that precision logistic regression ACCEPTs more reads than any other contender, and its weights can be read out (section 5); gradient-boosted trees are no better on 60 training vehicles.

Contenders that lost, and why:

- `weighted` (0.895): sensible hand weights, but not fitted, and it ignores confidence
- `gbt` (0.895): can model interactions, but on 60 training vehicles that buys little and its trees cannot be read aloud as weights
- `learned_ocr_similarity` (0.868): the measured confusion costs help, but a single string score cannot use the camera's make and colour or the read's confidence
- `edit_similarity` (0.859): charges 0->O as much as 0->7, so the commonest OCR error costs a full edit
- `ocr_edit_similarity` (0.859): hand table misses 1/4, H/4, 1/A, D/U, 1/T and prices 0/O like 5/S
- `jaro` (0.856): a transposition model plates do not need, and no notion of which glyphs OCR swaps
- `jaro_winkler` (0.856): its prefix bonus rewards the state code every hard negative shares too, so its scores bunch together and never calibrate to a safe ACCEPT
- `overlap` (0.852): normalised by the smaller q-gram set, so a truncated read contained in many plates scores 1.0 against all of them
- `jaccard` (0.852): a bag of bigrams ignores position, and plates share most bigrams (state, RTO, series), so the hard negatives score almost as high as the truth
- `ratcliff_obershelp` (0.844): longest-common-substring is order-aware but blind to confusions
- `tfidf` (0.844): up-weights rare bigrams, but the discriminating characters on a plate sit in common bigrams; like Jaccard it ignores order and OCR confusions
- `rule` (0.608): one substitution from a fixed table: fails on every two-error read and on confusions the table lacks, though what it does accept is right
- `soundex_similarity` (0.045): plates are not phonetic: Soundex keeps the first letter and codes the rest by consonant class, so whole series of plates share one code

Limits: 100 rendered vehicles, one font, one OCR engine (see BENCHMARK_NOISE.md section 6); 20 test vehicles, so differences of a few reads are within noise -- the paired win/loss counts above are the honest margin. Simulated camera context is an assumption, stated above, not a measurement.
